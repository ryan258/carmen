# Quiznauts place-bank import (October 29, 2026)

The 11 packs from `capitals-africa-carmen` onward in `trivia-bank.js` came from four question banks in `../quiznauts/questions/`: `capitals-hard-100.json`, `dish-origins-100.json`, `earth-superlatives-100.json`, and `extreme-earth-100.json`.

**Review status at import: unreviewed (superseded on October 30, 2026).** Quiznauts marked every one of these questions `unreviewed`. They were written from memory with linked sources, and the October 23 fact-check reset cleared all their sign-offs. The October 29 import did not check them against their sources. See [`2026-10-30-quiznauts-fact-check.md`](2026-10-30-quiznauts-fact-check.md) for the subsequent source, coordinate, and editorial review that retired 1 place and 11 facts and rewrote or tightened 103 facts across these 11 packs (now 239 places, 298 facts).

## What changed in the import

- Only questions whose answer is a place came over. Each became a fact about that place, and its clue is the fact with the place's name blanked. The Quiznauts multiple-choice distractors were dropped, because Carmen draws its choices from the other places in the pack.
- A numeric follow-up question about the same place was merged into that place's fact, for example Mammoth Cave's mapped length. Merged facts carry the sources of every question they absorbed.
- Sources are the Quiznauts links, all Wikipedia, plus the WMO extremes archive. Publishers are named from each link's host.
- Pack and place data that Quiznauts lacks was added here: approximate coordinates written from memory and unchecked, flag or type emoji, regions, and fictional suspects. Each family of packs reuses one roster of six suspects.
